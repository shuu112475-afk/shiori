第1章 総則

第1条 目的
この規程は、さくら総合病院（以下「病院」という。）の職員が業務のため出張する場合の手続および旅費の支給基準を定めるものである。

第2条 適用範囲
この規程は、すべての職員に適用する。学会参加、研修受講および病院が命じた外部会議への出席は、出張として取り扱う。
私的な資格取得のための移動および通勤は、出張に含まない。

第3条 出張の区分
出張は、次の3区分とする。
（1）日帰り出張とは、宿泊を伴わない出張をいう
（2）宿泊出張とは、1泊以上の宿泊を伴う国内の出張をいう
（3）海外出張とは、日本国外への出張をいう
勤務地から目的地までの片道の距離が50キロメートル未満の移動は近距離出張とし、日当を支給しない。

第2章 出張の手続

第4条 出張命令
出張は、所属長の命令により行う。職員が自ら申し出る場合も、事前に所属長の承認を得なければならない。

第5条 出張申請
出張しようとする職員は、出発日の7日前までに出張申請書を作成し、所属長の承認を経て事務部経理課に提出する。
急を要する場合はこの限りでないが、出発前までに口頭で所属長の承認を得て、事後速やかに申請書を提出しなければならない。
出張申請書には、目的、日程、行程、概算額および同行者を記載する。

第6条 旅行手配
航空券および宿泊施設の手配は、原則として病院が指定する旅行代理店（株式会社みなと商事）を通じて行う。
職員が自ら手配する場合は、指定代理店の見積額を超えないことを条件とし、領収書および明細を保存しなければならない。

第7条 仮払い
出張者は、概算額が3万円を超える場合に限り、仮払いを受けることができる。
仮払いを希望する職員は、出発日の3営業日前までに仮払申請書を事務部経理課に提出する。
仮払いの上限は、出張申請書に記載した概算額の80パーセントとする。

第3章 旅費

第8条 旅費の種類
旅費は、交通費、日当、宿泊費および支度料とする。支度料は海外出張の場合に限り支給する。

第9条 交通費
交通費は、最も経済的かつ合理的な経路および方法による実費を支給する。
（1）鉄道は普通車の指定席を基準とする。片道の営業キロが300キロメートルを超える区間については、特急列車および新幹線を利用できる
（2）グリーン車の利用は、役員に限り認める
（3）航空機は、原則としてエコノミークラスとする。ただし、片道の飛行時間が8時間を超える海外出張については、部長職以上に限りビジネスクラスを認める
（4）出発地から駅または空港までの間および目的地における市内交通費は、実費を支給する
（5）タクシーの利用は、公共交通機関の便がない場合、緊急を要する場合、または多量の資料もしくは機材を運搬する場合に限り認める

第10条 自家用車の使用
業務上の必要があり、あらかじめ所属長の承認を得た場合に限り、自家用車を使用することができる。
この場合、走行距離1キロメートルあたり30円を交通費として支給する。有料道路の通行料および駐車料金は実費を支給する。
自家用車を使用する職員は、任意保険に加入していることを事前に事務部経理課へ届け出るものとする。

第11条 日当
日当は、出張中の諸雑費に充てるため、次の基準により支給する。日当については領収書の提出を要しない。

| 役職区分                         | 日帰り出張 | 宿泊出張（1泊につき） |
| -------------------------------- | ---------- | --------------------- |
| 役員                             | 3,000円    | 4,000円               |
| 部長・科長・師長・課長（管理職） | 2,000円    | 3,000円               |
| 一般職員                         | 1,500円    | 2,500円               |

第12条 宿泊費
宿泊費は、実費を支給する。ただし、1泊あたりの上限額は次のとおりとする。

| 役職区分                         | 都市部   | 都市部以外 |
| -------------------------------- | -------- | ---------- |
| 役員                             | 15,000円 | 12,000円   |
| 部長・科長・師長・課長（管理職） | 12,000円 | 10,000円   |
| 一般職員                         | 10,000円 | 8,000円    |

この規程において「都市部」とは、東京都区部、横浜市、名古屋市、大阪市、京都市、札幌市および福岡市をいう。
学会が指定する宿舎を利用する場合その他やむを得ない事情により上限額を超えるときは、事前に事務部長の承認を得たうえで実費を支給する。
宿泊費に朝食代が含まれている場合であっても、日当は減額しない。

第13条 海外出張
海外出張の日当および宿泊費は、地域区分に応じて別表により定める。
支度料は、渡航1回につき30,000円を上限として支給する。ただし、同一年度内に2回目以降の渡航については支給しない。
海外旅行保険の保険料は、病院が負担する。

第14条 旅費を支給しない場合
主催者または招聘元から旅費、宿泊または食事の提供を受ける場合は、その相当額を控除して支給する。
出張先で私用のために日程を延長した部分の費用は、支給しない。

第4章 精算

第15条 精算期限
出張者は、帰着した日の翌日から起算して10日以内に、出張報告書および旅費精算書を事務部経理課に提出しなければならない。
月末をまたぐ出張の場合であっても、精算期限は前項による。
正当な理由なく精算期限を過ぎたときは、事務部経理課から所属長に通知し、所属長は速やかに提出させるものとする。

第16条 証拠書類
交通費および宿泊費の精算にあたっては、領収書、利用明細または交通系電子マネーの利用履歴を添付しなければならない。
領収書を紛失した場合は、支払証明書を作成し、所属長の確認印を受けて添付する。

第17条 仮払金の精算
仮払いを受けた職員は、精算時に過不足を清算する。
仮払金が精算額を上回るときは、精算書の提出と同時に差額を返納しなければならない。
精算期限後30日を経過してもなお返納されない場合は、翌月の給与から控除することがある。

第18条 支給日
精算により支給する旅費は、精算書を受理した月の翌月の給与支払日に、給与と併せて支払う。

第19条 不正受給
虚偽の申請により旅費を受給した職員は、受給額の全額を返還するとともに、就業規則に定める懲戒の対象となる。
