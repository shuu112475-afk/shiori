## 1. 基本理念と目的

さくら総合病院は、医療安全を医療の質の根幹と位置づけ、患者が安心して医療を受けられる環境の確保に組織として取り組む。
この指針は、当院における医療安全管理体制、インシデントの報告および分析の方法ならびに事故発生時の対応を定めるものであり、すべての職員に適用する。
当院は、事故の原因を個人の資質に求めるのではなく、業務手順および仕組みを改善することにより再発を防止する立場をとる。
この指針は、患者およびその家族から閲覧の求めがあったときは、これに応じるものとする。

## 2. 医療安全管理体制

### 2.1 医療安全管理委員会

医療安全管理委員会は、当院の医療安全に関する最高審議機関であり、毎月第3水曜日15時から開催する。緊急を要する場合は、委員長が臨時に招集する。
委員長は医療安全担当副院長とし、委員は院長、診療部長、看護部長、薬剤部長、臨床検査技師長、診療放射線技師長、事務部長、医事課長および医療安全管理者とする。
委員会は、報告されたインシデントの分析結果の評価、再発防止策の決定、指針および手順書の承認を行う。議事録は5年間保存する。

### 2.2 医療安全管理室

医療安全管理室は、医療安全管理委員会の実働部門として常設する。専従の医療安全管理者1名（看護師）を配置し、医師1名および薬剤師1名が兼任で加わる。相談および報告の窓口は内線2300とする。

### 2.3 医療安全推進者

各部署に医療安全推進者を1名以上配置する。医療安全推進者は、部署内でのインシデントレポート提出の促進、部署内カンファレンスの開催および医療安全管理室との連絡調整を担う。

### 2.4 各種安全管理責任者

当院は、医薬品安全管理責任者、医療機器安全管理責任者および医療放射線安全管理責任者をそれぞれ任命する。各責任者は、担当領域の業務手順書の整備、職員研修の実施および使用実績の把握を行い、その状況を医療安全管理委員会へ年1回報告する。

## 3. インシデントとアクシデントの定義

「インシデント」とは、日常の医療現場で発生した、患者に被害を及ぼすことはなかったが、ヒヤリとした、またはハッとした出来事をいう。誤った行為が患者に実施される前に発見された事例を含む。
「アクシデント」とは、医療行為の過程において患者に望ましくない結果が生じた事例をいう。過失の有無を問わない。
この指針において「インシデントレポート」とは、両者を区別せず、次章の影響度分類レベル0から5までのすべての事例について提出する報告をいう。

## 4. 患者影響度分類

報告された事例は、患者への影響の程度に応じて次のとおり分類する。分類は報告者が暫定的に付し、医療安全管理室が確定する。

| レベル   | 内容                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| レベル0  | 誤った行為が発生したが、患者には実施されなかった                                                     |
| レベル1  | 誤った行為を患者に実施したが、結果として患者に影響を及ぼさなかった                                   |
| レベル2  | 処置や治療は行わなかったが、観察の強化やバイタルサインの確認など、安全確認のための対応が必要となった |
| レベル3a | 簡単な処置や治療を要した                                                                             |
| レベル3b | 濃厚な処置や治療を要した                                                                             |
| レベル4a | 永続的な障害や後遺症が残ったが、有意な機能障害や美容上の問題は伴わない                               |
| レベル4b | 永続的な障害や後遺症が残り、有意な機能障害や美容上の問題を伴う                                       |
| レベル5  | 患者が死亡した（原疾患の自然経過によるものを除く）                                                   |

## 5. インシデントレポートの提出

### 5.1 提出の基準

職員は、レベル0からレベル5までのすべての事例についてインシデントレポートを提出しなければならない。患者に影響が及ばなかったレベル0およびレベル1の事例こそ、再発防止に有用な情報である。
自らが当事者となった事例のほか、他者の事例を発見した場合も提出の対象とする。同一事例について複数の職員が提出することを妨げない。
提出は、電子カルテの医療安全報告システム（様式MS-1）から行う。

### 5.2 提出期限

| 影響度                 | 提出期限                                                                         |
| ---------------------- | -------------------------------------------------------------------------------- |
| レベル0からレベル2まで | 発生または発見から72時間以内に提出する                                           |
| レベル3a               | 発生または発見から48時間以内に提出する                                           |
| レベル3b以上           | ただちに所属長および医療安全管理室へ口頭で報告し、24時間以内にレポートを提出する |
| レベル4およびレベル5   | ただちに所属長、医療安全管理室および院長へ報告する。夜間休日は当直師長を経由する |

### 5.3 報告経路

通常の報告経路は、発見者から所属長、医療安全推進者、医療安全管理室、医療安全管理委員会、院長の順とする。
レベル3b以上の事例については、この経路と並行して、発見者または所属長から医療安全管理室および院長へ直接報告する。
医療安全管理室は、提出されたレポートを週1回集計し、月次で医療安全管理委員会へ報告する。分析を要する事例については、関係者を集めて根本原因分析を行う。

### 5.4 報告者の保護

インシデントレポートは、再発防止のみを目的として用いる。報告を行ったことを理由として、報告者および当事者に対し懲戒その他の不利益な取扱いをしない。
レポートの内容を人事評価に用いてはならない。報告者が希望する場合は、匿名での提出を認める。
所属長は、部署内でレポートの提出を抑制するような言動を行ってはならない。

## 6. 医療安全管理室の役割

医療安全管理室は、次の業務を行う。

（1）インシデントレポートの収集、分類、分析および再発防止策の立案
（2）院内ラウンドによる業務手順の遵守状況の確認
（3）医療安全に関する職員研修の企画および実施
（4）重大事象発生時の初動対応の支援および記録の確保
（5）医療安全に関する情報の院内周知（医療安全ニュースを月1回発行する）

## 7. 重大事象発生時の対応

レベル3b以上の事象が発生したときは、患者の安全確保を最優先とし、必要な処置を行うとともに、ただちに応援を要請する。
患者およびその家族に対しては、判明している事実を誠実に説明する。説明は主治医または診療科長が行い、説明した内容、日時および同席者を診療録に記録する。推測に基づく説明および責任の所在に関する断定的な発言は行わない。
関係する器材、薬剤の空容器および記録類は、原状のまま保全する。診療録は事後に修正せず、追記が必要な場合は追記した日時を明記する。
院長は、必要と認めるときは院内事故調査委員会を設置する。外部委員の招聘および院外への報告の要否は、院長が判断する。

## 8. 患者相談窓口

当院は、患者およびその家族からの相談、意見および苦情を受け付ける窓口として医療相談室を設置する。受付は内線2500、平日9時から17時までとする。
相談内容のうち医療安全に関わるものは、医療相談室から医療安全管理室へ速やかに情報提供する。相談したことを理由として、患者が診療上不利益を受けることはない。

## 9. 職員研修

全職員は、医療安全に関する研修を年2回以上受講しなければならない。研修は医療安全管理室が企画し、院内で発生した事例に基づく内容を含める。
新規採用者に対しては、配属前に医療安全の基本、報告の方法および患者確認の手順に関する研修を行う。医療安全管理室は受講記録を保管し、未受講者の一覧を年度末に所属長へ通知する。
