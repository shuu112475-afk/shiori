## 1. 総則

### 1.1 目的

このマニュアルは、さくら総合病院（345床・二次救急）において、患者および職員を感染から守るために必要な基本的な考え方と具体的な手順を定めるものである。

### 1.2 適用範囲

このマニュアルは、当院に勤務するすべての職員に適用する。委託業者、実習生、ボランティアおよび研修受入者にも、その業務の範囲において遵守を求める。

### 1.3 職員の責務

職員は、このマニュアルを遵守する。定めのない事態が生じたときは、自己判断で対応せず、感染管理室に相談する。

## 2. 標準予防策

### 2.1 基本的な考え方

標準予防策とは、感染症の有無にかかわらず、すべての患者に対して等しく適用する感染対策をいう。血液、体液、分泌物、排泄物、粘膜および損傷した皮膚は、感染性があるものとして取り扱う。

### 2.2 適用の原則

（1）これらに触れる可能性がある処置の前に、必要な個人防護具を選択して着用する
（2）処置の前後には、必ず手指衛生を行う
（3）使用した器材は、他の患者に使用する前に洗浄、消毒または滅菌を行う
（4）血液または体液が飛散する可能性がある場合は、目、鼻および口の粘膜を防護する

## 3. 手指衛生

### 3.1 手指衛生の5つのタイミング

すべての職員は、次の5つのタイミングで手指衛生を行う。

（1）患者に触れる前
（2）清潔・無菌操作の前
（3）体液に曝露された可能性のある場合の後
（4）患者に触れた後
（5）患者周辺の環境や物品に触れた後

### 3.2 手指衛生の方法

擦式アルコール手指消毒薬を用いる場合は、手指の全表面に行き渡らせ、乾燥するまで、おおむね20秒以上すり込む。
流水と石けんによる手洗いを行う場合は、40秒から60秒かけて洗浄し、ペーパータオルで完全に乾燥させる。
目に見える汚染があるとき、およびアルコールが効きにくい病原体が疑われる患者に対応した後は、擦式消毒薬ではなく流水と石けんによる手洗いを行う。

### 3.3 手指衛生を妨げる要因の排除

勤務中は、指輪、腕時計および人工爪を着用しない。爪は指先から出ない長さに保つ。

### 3.4 遵守率のモニタリング

感染管理認定看護師は、直接観察法により各部署の手指衛生遵守率を月1回測定する。目標値は80パーセント以上とし、測定結果は翌月の感染対策委員会に報告するとともに、各部署に掲示する。

## 4. 個人防護具（PPE）

### 4.1 選択の基準

個人防護具は、想定される曝露の内容に応じて選択する。血液または体液が飛散する可能性がある処置では、ガウンとゴーグルを追加する。

### 4.2 着用の手順

個人防護具は、次の順序で着用する。

（1）手指衛生
（2）ガウンまたはエプロン
（3）マスク
（4）ゴーグルまたはフェイスシールド
（5）手袋（ガウンの袖口を覆うように着用する）

### 4.3 脱衣の手順

汚染された防護具から自らを汚染させないよう、次の順序で脱衣する。マスクは病室を出てから外す。

（1）手袋
（2）手指衛生
（3）ゴーグルまたはフェイスシールド
（4）ガウン（表面に触れないよう内側に丸めて脱ぐ）
（5）手指衛生
（6）マスク（ゴム紐を持って外す）
（7）手指衛生

### 4.4 手袋の取扱い

手袋は患者ごとに交換し、同一患者であっても汚染部位から清潔部位へ移る際には交換する。手袋を着用したまま電子カルテ端末やドアノブに触れてはならない。手袋の再利用は禁止する。

### 4.5 N95マスク

空気予防策の対象となる患者に対応する職員は、N95マスクを着用する。
N95マスクのフィットテストは、対象職員に対し年1回実施する。着用のたびにユーザーシールチェックを行い、密着が得られない場合は別のサイズまたは型式を使用する。密着を妨げるため、対象職員はひげを剃るものとする。

## 5. 感染経路別予防策

標準予防策に加えて、次の予防策を適用する。適用の開始および解除は、主治医と感染管理室が協議して決定する。

| 予防策     | 病室               | 主な防護具       | ベッド間隔等                         |
| ---------- | ------------------ | ---------------- | ------------------------------------ |
| 接触予防策 | 個室または集団隔離 | 手袋、ガウン     | 器材は可能な限り専用化する           |
| 飛沫予防策 | 個室が望ましい     | サージカルマスク | 他の患者と1メートル以上離す          |
| 空気予防策 | 陰圧個室           | N95マスク        | 扉は常時閉鎖し、入退室を最小限にする |

病室の入口には、感染対策の種別を示す標示板を掲示する。標示板には病名を記載せず、必要な防護具のみを表示する。

## 6. 針刺し・切創および血液体液曝露事故

### 6.1 予防

使用済みの注射針はリキャップしてはならない。針は使用した者本人が、使用した場所に持参した耐貫通性の廃棄容器へただちに廃棄する。
廃棄容器は容量の8割に達した時点で閉栓し、交換する。安全機能付き器材が配備されている手技では、必ずその機能を作動させる。

### 6.2 受傷直後の対応

受傷したときは、ただちに処置を中断し、曝露部位を流水と石けんで十分に洗浄する。粘膜に曝露した場合は、流水または生理食塩水で15分以上洗い流す。
受傷した職員が単独で対応を続けてはならない。周囲の職員に応援を求め、業務の代行者を立てる。

### 6.3 報告フロー

報告は次の時間の目安で行う。夜間および休日であっても、翌朝まで待ってはならない。

| 時間の目安               | 対応                                                   | 連絡先                                         |
| ------------------------ | ------------------------------------------------------ | ---------------------------------------------- |
| ただちに                 | 曝露部位の洗浄、業務の中断                             | 現場対応                                       |
| 5分以内                  | 所属長へ口頭で報告する                                 | 各部署 所属長                                  |
| 30分以内                 | 感染管理室へ電話報告する                               | 感染管理室 内線2201（平日8時30分から17時15分） |
| 30分以内（時間外・休日） | 当直師長へ電話報告する。当直師長が感染管理室へ引き継ぐ | 当直師長 PHS7001                               |
| 1時間以内                | 曝露源患者への説明と感染症検査の同意取得               | 主治医（時間外は当直医 PHS7010）               |
| 2時間以内                | 受傷者本人が救急外来を受診し、初回採血を受ける         | 救急外来 内線1911                              |
| 受診時                   | 曝露後予防の要否を判断する                             | 感染症内科 オンコール PHS7020                  |
| 24時間以内               | 「針刺し・切創等報告書」（様式ICT-3）を提出する        | 感染管理室                                     |
| 7日以内                  | 労働者災害補償保険の申請書類を提出する                 | 事務部人事課 内線3110                          |

曝露源患者の感染症検査の同意取得は、主治医または当直医が行う。受傷した本人が患者に直接依頼してはならない。
曝露後予防の要否および内容は、感染症内科医が判断する。職員が自らの判断で薬剤を使用してはならない。

### 6.4 記録と追跡

感染管理室は、受傷時、1か月後、3か月後および6か月後の採血結果を管理し、受傷者に個別に結果を通知する。
針刺し・切創の発生状況は、部署別・器材別に集計し、四半期ごとに感染対策委員会へ報告する。報告は再発防止のために行うものであり、報告した職員に不利益な取扱いをしない。

## 7. 感染対策の組織体制

### 7.1 感染対策委員会

感染対策委員会は、当院の感染対策に関する最高意思決定機関であり、毎月第2火曜日16時30分から開催する。
委員長は感染管理担当副院長とし、委員は院長、看護部長、薬剤部長、臨床検査技師長、診療放射線技師長、事務部長、感染管理認定看護師および各診療科の代表とする。
委員会は、感染対策の方針決定、サーベイランス結果の評価、アウトブレイク時の対応方針の決定およびマニュアルの承認を行う。

### 7.2 感染管理室

感染管理室は、感染対策委員会の実働部門として常設し、感染管理認定看護師が専従で配置される。相談窓口は内線2201とする。

### 7.3 感染制御チーム（ICT）

感染制御チームは、医師、感染管理認定看護師、薬剤師および臨床検査技師の4職種で構成し、毎週水曜日に院内ラウンドを実施する。
ラウンドでは、手指衛生の実施状況、個人防護具の使用状況、環境整備および隔離の適否を確認し、その場で指導する。指摘事項は所属長へ書面で通知する。

### 7.4 抗菌薬適正使用支援チームおよびリンクスタッフ

抗菌薬適正使用支援チームは、週1回カンファレンスを開催し、抗菌薬の使用状況について主治医への助言を行う。
各部署に1名以上のリンクスタッフを配置する。リンクスタッフ会は月1回開催し、部署における感染対策の推進役を担う。

## 8. 職員の健康管理

入職時に、麻疹、風疹、水痘および流行性耳下腺炎の4疾患について抗体価の証明書を提出する。基準を満たさない場合は、病院の費用負担でワクチンを接種する。
インフルエンザワクチンは、毎年10月から11月にかけて院内接種を実施する。
職員が発熱、嘔吐、下痢または発疹を認めたときは、出勤前に所属長へ連絡し、指示を受ける。自己判断で出勤してはならない。

## 9. アウトブレイク対応

同一部署において、1週間以内に同一の病原体による感染症患者が3名以上発生したときは、アウトブレイクの疑いとして、ただちに感染管理室へ報告する。
感染管理室は、報告を受けてから24時間以内に対策会議を招集し、患者の隔離、新規入室の制限および環境の消毒について方針を決定する。保健所への報告の要否は院長が判断する。

## 10. 教育と評価

全職員は、感染対策に関する研修を年2回受講しなければならない。受講率100パーセントを目標とし、感染管理室は年度末に未受講者の一覧を所属長へ通知する。
