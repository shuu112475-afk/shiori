第1章 総則

第1条 目的
この規則は、さくら総合病院（以下「病院」という。）に勤務する職員の労働条件および服務規律に関する事項を定めたものである。

第2条 適用範囲
この規則は、第5条の手続により採用された正職員に適用する。
パートタイム職員、有期契約職員および嘱託職員については別に定める規程によるものとし、当該規程に定めのない事項はこの規則を準用する。

第3条 規則遵守の義務
病院および職員は、ともにこの規則を遵守し、誠実に各々の義務を履行しなければならない。この規則に定めのない事項は、労働基準法その他の関係法令による。

第4条 用語の定義
「所属長」とは、職員が所属する部署の長（部長、科長、師長、課長）をいう。
「年度」とは、毎年4月1日に始まり翌年3月31日に終わる期間をいう。
「勤怠システム」とは、病院が指定する電子的な出退勤記録システムをいう。

第2章 採用および異動

第5条 採用手続
病院は、選考試験および面接に合格した者を職員として採用する。採用の可否は、事務部人事課が取りまとめ、院長が決定する。

第6条 採用時の提出書類
採用された者は、採用日から2週間以内に、履歴書、住民票記載事項証明書、資格免許証の写し、雇用保険被保険者証の写し、誓約書および身元保証書を事務部人事課に提出しなければならない。
記載事項に変更が生じたときは、変更の日から2週間以内に届け出なければならない。

第7条 試用期間
新たに採用した者については、採用の日から3か月間を試用期間とする。
引き続き見極めを要すると認めるときは3か月を限度として延長することがあり、この場合の試用期間は通算して6か月を超えないものとする。試用期間は勤続年数に通算する。

第8条 労働条件の明示
病院は、採用に際し、賃金、就業場所、従事する業務および労働時間を記載した労働条件通知書を交付する。

第9条 人事異動
病院は、業務上の必要がある場合、勤務場所もしくは従事する業務の変更または職位の変更を命じることがある。職員は正当な理由なくこれを拒むことができない。

第10条 休職
職員が業務外の傷病により欠勤が引き続き1か月を超えたとき、その他病院が必要と認めたときは、休職を命じることがある。
傷病による休職の期間は、勤続3年未満の職員は6か月、勤続3年以上の職員は12か月を上限とする。休職期間中の給与は支給せず、休職期間は勤続年数に通算しない。

第11条 復職
傷病による休職からの復職にあたっては主治医の診断書を提出させ、産業医の面談を経て院長が復職の可否を決定する。
休職期間が満了してもなお休職事由が消滅しないときは、休職期間の満了をもって退職とする。

第3章 勤務時間、休憩および休日

第12条 所定労働時間
所定労働時間は、1日8時間、1週40時間とする。
病院は、労使協定に基づき1か月単位の変形労働時間制を採用することがある。

第13条 始業および終業の時刻ならびに休憩時間
日勤の始業時刻は午前8時30分、終業時刻は午後5時30分とし、休憩時間は正午から午後1時までの60分とする。
業務の都合により、所属長の指示によって休憩時間を変更することがある。

第14条 交替制勤務
看護部その他病院が指定する部署の職員には、次の勤務区分による交替制勤務を命じることがある。勤務表は前月20日までに所属長が作成し、職員に周知する。

| 勤務区分   | 始業時刻 | 終業時刻 | 休憩時間 |
| ---------- | -------- | -------- | -------- |
| 日勤       | 8:30     | 17:30    | 60分     |
| 準夜勤     | 16:30    | 翌1:30   | 60分     |
| 深夜勤     | 0:30     | 9:30     | 60分     |
| 二交替夜勤 | 16:30    | 翌9:30   | 120分    |

第15条 休日
休日は、日曜日および土曜日、国民の祝日、年末年始（12月30日から翌年1月3日まで）ならびに病院が指定する日とする。
交替制勤務者については、前項にかかわらず4週間を通じて8日以上の休日を勤務表により指定する。

第16条 時間外労働および休日労働
業務の都合によりやむを得ない場合は、労使協定の範囲内で所定労働時間を超えて、または休日に勤務させることがある。
時間外労働および休日労働は所属長の事前命令によるものとし、職員が自らの判断で行うことはできない。事前命令を得られなかった場合は、翌勤務日までに事後承認を得なければならない。

第17条 宿日直勤務
病院は、業務上必要がある場合、職員に宿直または日直の勤務を命じることがある。回数および手当の取扱いは、別に定める宿日直勤務規程による。

第18条 出退勤の記録
職員は、始業時および終業時に勤怠システムにより自ら出退勤を記録しなければならない。他の職員に代わって記録することは、理由のいかんを問わず禁止する。

第19条 遅刻、早退および私用外出
遅刻、早退または私用外出をしようとする職員は、あらかじめ所属長に届け出て承認を受けなければならない。事前に届け出ることができなかったときは、速やかに連絡し、出勤後ただちに届け出るものとする。

第20条 適用除外
管理監督者については、第12条から第16条までの規定を適用しない。ただし、深夜労働および労働時間の把握に関する規定は適用する。

第4章 休暇

第21条 休暇の種類
職員の休暇は、年次有給休暇、特別休暇、育児休業等および欠勤とする。取得にあたっては、業務に支障が生じないようあらかじめ所属長と調整するものとする。

第22条 年次有給休暇
病院は、採用の日から6か月間継続して勤務し、所定労働日の8割以上出勤した職員に対し、10日の年次有給休暇を付与する。以後は、継続勤務年数に応じて次表のとおり付与する。

| 継続勤務年数 | 0.5年 | 1.5年 | 2.5年 | 3.5年 | 4.5年 | 5.5年 | 6.5年以上 |
| ------------ | ----- | ----- | ----- | ----- | ----- | ----- | --------- |
| 付与日数     | 10日  | 11日  | 12日  | 14日  | 16日  | 18日  | 20日      |

（1）年次有給休暇は、1日単位のほか半日単位で取得することができる。時間単位での取得は、労使協定の範囲内で1年につき5日を限度とする。
（2）年次有給休暇を取得しようとする職員は、原則として取得しようとする日の3日前までに、勤怠システムにより所属長へ届け出るものとする。ただし、傷病その他やむを得ない事由による場合は、事後の届出を認めることがある。
（3）その年度に取得しなかった年次有給休暇は、翌年度に繰り越すことができる。繰り越すことができる期間は2年間とし、繰越分を含めて保有できる年次有給休暇の日数は40日を上限とする。上限を超える日数は消滅し、買い上げは行わない。
（4）年次有給休暇の請求が事業の正常な運営を妨げると認められる場合、病院は他の時季に変更することがある。
（5）年次有給休暇の残日数は、勤怠システムおよび毎月の給与明細で確認することができる。

第23条 年次有給休暇の時季指定
年次有給休暇を10日以上付与された職員については、付与日から1年以内に5日について、病院が職員の意見を聴いたうえで時季を指定して取得させる。ただし、職員が自ら請求して取得した日数および計画的付与により取得した日数は、この5日から控除する。

第24条 特別休暇
職員は、次に定める特別休暇を取得することができる。特別休暇の期間は有給とする。事由を証明する書類を添えて所属長に届け出るものとする。

| 事由                                     | 日数                      |
| ---------------------------------------- | ------------------------- |
| 本人の結婚                               | 5日                       |
| 配偶者の出産                             | 3日                       |
| 父母、配偶者または子の死亡               | 5日                       |
| 祖父母、兄弟姉妹または配偶者の父母の死亡 | 3日                       |
| 夏季休暇                                 | 3日（7月から9月までの間） |
| 公務による休暇（裁判員、選挙立会等）     | 必要な日数                |

第25条 産前産後休業
6週間（多胎妊娠の場合は14週間）以内に出産予定の女性職員が請求したときは、産前休業を与える。
産後8週間を経過しない女性職員は就業させない。ただし、産後6週間を経過した女性職員が請求し、医師が支障がないと認めた業務に就かせることは差し支えない。産前産後休業の期間中の給与は支給しない。

第26条 育児休業、介護休業等
職員の育児休業、出生時育児休業、介護休業、子の看護等休暇、介護休暇および短時間勤務の取扱いについては、別に定める育児介護休業規程による。

第27条 母性健康管理
妊娠中および出産後1年を経過しない女性職員が、保健指導または健康診査を受けるために必要な時間を請求したときは、勤務時間中であってもこれを認める。
妊娠中の女性職員が請求したときは、軽易な業務への転換、時間外労働および深夜業の制限その他必要な措置を講じる。

第28条 欠勤
傷病その他の事由により勤務できないときは、始業時刻までに所属長に連絡しなければならない。
私傷病による欠勤が引き続き7日を超えるときは、医師の診断書を提出しなければならない。欠勤の期間は無給とする。

第5章 給与

第29条 給与の構成
給与は、基本給、職務手当、資格手当、住宅手当、通勤手当、扶養手当、夜勤手当および時間外勤務手当をもって構成する。細目は別に定める給与規程による。

第30条 給与の計算期間および支払日
給与の計算期間は毎月1日から当月末日までとし、支払日は翌月10日とする。支払日が休日にあたるときは、その直前の営業日に繰り上げて支給する。
給与は、職員が指定する本人名義の金融機関口座に振り込む方法により支払う。

第31条 割増賃金
時間外労働、休日労働および深夜労働に対しては、次の割増率により計算した割増賃金を支給する。

| 種別                                  | 割増率       |
| ------------------------------------- | ------------ |
| 時間外労働（1か月60時間以内の部分）   | 25パーセント |
| 時間外労働（1か月60時間を超える部分） | 50パーセント |
| 法定休日労働                          | 35パーセント |
| 深夜労働（午後10時から午前5時まで）   | 25パーセント |

第32条 昇給および賞与
昇給は、原則として毎年4月1日に、前年度の人事評価の結果に基づいて行う。
賞与は、原則として毎年6月および12月に、病院の業績および勤務成績に応じて支給する。支給対象は支給日に在籍する職員とする。

第33条 退職金
勤続3年以上の職員が退職または解雇されたときは、別に定める退職金規程により退職金を支給する。懲戒解雇された者には、退職金の全部または一部を支給しないことがある。

第6章 服務規律

第34条 服務の基本
職員は、病院の職員としての自覚を持ち、患者およびその家族に対して誠実かつ丁寧に接するとともに、職務上の指示命令に従い、相互に協力して職務を遂行しなければならない。

第35条 遵守事項
職員は、次の事項を守らなければならない。
（1）勤務時間中は職務に専念し、みだりに職場を離れないこと
（2）職員証を常時着用し、患者から見える位置に表示すること
（3）指定された服装および身だしなみの基準を守ること
（4）病院の施設、備品および医療機器を私用に供しないこと
（5）飲酒しての勤務および勤務中の飲酒をしないこと
（6）患者およびその家族から、金品その他の利益の供与を受けないこと

第36条 秘密保持
職員は、業務上知り得た患者の診療情報、職員の個人情報、病院の経営情報その他の秘密を、正当な理由なく他に漏らしてはならない。この義務は退職後においても同様とする。
職員は、採用時および退職時に、秘密保持に関する誓約書を提出しなければならない。

第37条 診療情報および個人情報の取扱い
職員は、業務上必要な範囲を超えて診療情報を閲覧してはならない。自己、家族または知人の診療記録を業務外の目的で閲覧することは禁止する。閲覧履歴は記録され、定期的に監査される。
電子カルテの利用者IDおよびパスワードは、他人に貸与または開示してはならない。診療情報を含むデータを、病院が許可した機器以外に保存し、または病院外に持ち出してはならない。

第38条 ハラスメントの禁止
職員は、職場におけるパワーハラスメント、セクシュアルハラスメント、妊娠・出産・育児休業等に関するハラスメントその他の言動により、他の職員の就業環境を害してはならない。
ハラスメントに関する相談窓口は、事務部人事課および外部相談窓口とする。相談したことを理由に不利益な取扱いを受けることはない。

第39条 副業および兼業
職員が他の事業所に雇用され、または自ら事業を営もうとするときは、あらかじめ所定の様式により届け出て、院長の承認を得なければならない。
病院の業務に支障をきたすおそれがあるとき、病院の信用を害するおそれがあるとき、または秘密保持義務に反するおそれがあるときは、承認しない。

第40条 情報発信および広報
職員は、個人が運営する会員制交流サイトその他の媒体において、患者、他の職員または病院の内部情報が特定される内容を発信してはならない。病院を代表して取材に応じる場合は、事前に事務部総務課を通じて院長の承認を得るものとする。

第7章 安全衛生および災害補償

第41条 健康診断
病院は、職員に対し、採用時および毎年1回、定期健康診断を行う。深夜業を含む業務に常時従事する職員に対しては、6か月ごとに1回、健康診断を行う。
職員は正当な理由なくこれを拒むことができない。結果により必要と認めるときは、就業場所の変更、業務の転換または労働時間の短縮その他の措置を講じる。

第42条 ストレスチェック
病院は、職員に対し毎年1回ストレスチェックを実施する。高ストレスと判定された職員から申出があったときは、医師による面接指導を行う。個人結果は本人の同意なく病院に提供されない。

第43条 就業の禁止および災害補償
感染症にかかった職員その他病院が就業を不適当と認めた職員については、就業を禁止することがある。具体的な取扱いは、別に定める感染対策マニュアルによる。
職員が業務上または通勤途上において負傷し、疾病にかかり、または死亡したときは、労働者災害補償保険法の定めるところにより補償を受けるものとする。この場合、ただちに所属長および事務部人事課に報告しなければならない。

第8章 表彰および懲戒

第44条 表彰
病院は、職員が業務上有益な改善を行い病院の運営に貢献したとき、永年にわたり誠実に勤務しその成績が優秀であるとき、または災害もしくは事故を未然に防止したときは、表彰を行う。

第45条 懲戒の種類
懲戒は、その情状に応じて次の5種類とする。

| 種類     | 内容                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| けん責   | 始末書を提出させ、将来を戒める                                                |
| 減給     | 始末書を提出させ、給与を減額する                                              |
| 出勤停止 | 始末書を提出させ、7日以内の期間を定めて出勤を停止し、その間の給与を支給しない |
| 諭旨退職 | 退職願の提出を勧告する。勧告に応じないときは懲戒解雇とする                    |
| 懲戒解雇 | 予告期間を設けずに即時解雇する                                                |

減給は、1回の額が平均賃金の1日分の半額を超えず、かつ総額が一賃金支払期における給与総額の10分の1を超えない範囲で行う。

第46条 けん責、減給または出勤停止の事由
職員が次のいずれかに該当するときは、けん責、減給または出勤停止に処する。
（1）正当な理由なく無断欠勤が3日以内であるとき
（2）正当な理由なくしばしば遅刻、早退または欠勤を繰り返したとき
（3）職務上の指示命令に従わず、または過失により病院に損害を与えたとき
（4）この規則に定める服務規律に違反したとき

第47条 諭旨退職または懲戒解雇の事由
職員が次のいずれかに該当するときは、諭旨退職または懲戒解雇に処する。
（1）正当な理由なく無断欠勤が14日以上に及び、出勤の督促に応じないとき
（2）重要な経歴を偽って採用されたとき
（3）故意または重大な過失により病院に重大な損害を与えたとき
（4）業務上知り得た患者の診療情報を外部に漏らし、または不正な目的で利用したとき
（5）病院内で暴行、脅迫その他の犯罪行為を行ったとき
（6）ハラスメントにより他の職員の就業環境を著しく害し、または前条各号の行為を繰り返して改善の見込みがないとき

第48条 自宅待機および損害賠償
懲戒に該当する疑いのある事案の調査に必要があるときは、調査の期間中、職員に自宅待機を命じることがある。自宅待機は懲戒処分ではなく、その期間中は通常の給与を支給する。
職員が故意または重大な過失により病院に損害を与えたときは、懲戒処分とは別に、その損害の全部または一部の賠償を求めることがある。

第9章 退職および解雇

第49条 退職
本人が退職を申し出て病院が承認したとき、定年に達したとき、休職期間が満了してもなお休職事由が消滅しないとき、死亡したとき、または有期の労働契約の期間が満了したときは、退職とする。

第50条 退職の手続
自己都合により退職しようとする職員は、退職を希望する日の30日前までに、所定の様式による退職願を所属長を経て事務部人事課に提出しなければならない。
退職願を提出した職員は、退職日までに業務の引継ぎを完了し、職員証、健康保険証、貸与品および業務上作成した記録類を返還しなければならない。

第51条 定年および再雇用
定年は満60歳とし、定年に達した日以後の最初の3月31日をもって退職とする。
定年に達した職員が希望する場合は、満65歳に達する日以後の最初の3月31日までを限度として、嘱託職員として再雇用する。再雇用後の労働条件は個別に定める。

第52条 解雇
勤務成績が著しく不良で向上の見込みがなく他の職務にも転換できないとき、精神または身体の障害により業務に耐えられないと認められるとき、事業の縮小その他やむを得ない業務上の都合が生じたとき、または第47条に定める懲戒解雇の事由に該当するときは、解雇することがある。

第53条 解雇の予告
前条により職員を解雇する場合は、少なくとも30日前に予告するか、または平均賃金の30日分以上の解雇予告手当を支払う。予告の日数は、解雇予告手当を支払った日数だけ短縮することができる。
懲戒解雇の場合において、労働基準監督署長の認定を受けたときは、予告および予告手当の支払を行わない。
