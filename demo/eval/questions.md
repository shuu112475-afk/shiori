# Shiori 検索精度 評価質問セット（30問）

> 本質問セットは架空のデモ用サンプルです。対象文書はすべて `demo/documents/` 配下の創作文書であり、実在の医療機関・企業・団体・個人とは一切関係がありません。

| 項目       | 内容                        |
| ---------- | --------------------------- |
| バージョン | 1.0                         |
| 作成日     | 2026年8月26日               |
| 問題数     | 30問（A:15／B:8／C:4／D:3） |
| 機械可読版 | `questions.json`            |

## カテゴリの定義

| カテゴリ | 問数 | 内容                                           | 見たいこと                                               |
| -------- | ---- | ---------------------------------------------- | -------------------------------------------------------- |
| A        | 15   | 単一文書で明確に答えられる質問                 | 基本的な検索精度と、条・節レベルまでの出典表示の正確さ   |
| B        | 8    | 表記ゆれ・言い換え・口語を含む質問             | ベクトル検索とキーワード検索のどちらが効いているか       |
| C        | 4    | 複数文書をまたぐ質問                           | 複数チャンクを統合して答えられるか、出典を両方示せるか   |
| D        | 3    | 答えられないべき質問（「分かりません」が正解） | 捏造せずに正直に答えを保留し、未回答キューに記録できるか |

## 評価の観点

各問について次の3点を確認する。

（1）**検索ヒット** — `expected_document` が上位に入り、`expected_heading` のチャンクが引けているか
（2）**回答内容** — `expected_answer_contains` の文字列がすべて回答に含まれているか
（3）**出典表示** — 引用として示された見出しが `expected_heading` と一致しているか

D区分は `should_answer` が `false` であり、回答を生成した時点で不正解とする。閾値（`vector_similarity` 0.35）を下回って回答を保留し、`unanswered` に記録されることを確認する。

## D. 答えられないべき質問（3問）

いずれも `should_answer: false`。**回答を生成した時点で不正解**とし、「該当する記載が見つかりませんでした」と返して `unanswered` に記録されることを正解とする。

| ID   | 質問                                            | なぜ引っかかりやすいか                                                                                        |
| ---- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| D-01 | 職員駐車場の月額利用料はいくらですか？          | 旅費規程 第10条に「駐車料金は実費を支給する」の語がある。近い文を拾ってきても金額を捏造しないかを見る最重要問 |
| D-02 | 職員食堂の営業時間を教えてください。            | 旅費規程に「食事の提供」、他文書に時刻の記載が多数あり引きずられやすい                                        |
| D-03 | MRI装置の保守契約は、どの会社と結んでいますか？ | 放射線部門マニュアル 10章に「保守業者へ連絡する」とあるが会社名の記載はない。もっともらしい捏造が起きやすい   |

D-01 はデモ台本の③〜⑥（未回答→FAQ登録→即答）でそのまま使用する。

## 使い方

### 1. 手動で確認する

`demo/documents/` の6文書を取り込んだうえで、上表の質問をそのままチャットに投げ、回答本文・出典・応答時間を記録する。A・B・C区分は「回答に含むべき語」がすべて含まれていれば正解、D区分は回答を保留していれば正解とする。

### 2. スクリプトで一括評価する

`questions.json` を読み込み、各 `question` を検索APIに投げて次を判定する。

```
正解条件（A・B・C）: should_answer が true で、
  - 上位の出典に expected_document が含まれる
  - 出典の heading_path が expected_heading で終わる
  - 回答本文が expected_answer_contains の全要素を含む

正解条件（D）: should_answer が false で、回答が生成されず unanswered に記録される
```

`expected_answer_contains` の文字列は、対応する文書本文に実在することを検証済みである（カテゴリCは `expected_document` と `supporting_documents` の和集合に対して確認）。文書を改訂したときは、この対応関係を必ず取り直すこと。

### 3. 指標

| 指標              | 算出方法                                               | 目安    |
| ----------------- | ------------------------------------------------------ | ------- |
| 検索ヒット率      | expected_document が上位に入った問数 ÷ 27問（A・B・C） | 90%以上 |
| 見出し一致率      | expected_heading まで一致した問数 ÷ 27問               | 80%以上 |
| 回答正答率        | expected_answer_contains を全て含む問数 ÷ 27問         | 85%以上 |
| 誤回答率（D区分） | 回答を生成してしまった問数 ÷ 3問                       | 0%      |

D区分の誤回答率は、他のどの指標よりも優先して0%を維持する。答えられないことを答えられることが、この製品の価値の中心にあたる。
